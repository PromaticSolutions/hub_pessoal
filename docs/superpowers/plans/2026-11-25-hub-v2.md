# Personal Task Hub v2 — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evoluir o app v1 com visual refinado, dropdowns próprios, abas estilo navegador, Todas as Tarefas com edição em massa, Minha semana redesenhada, cores no Kanban, Meu Dia, Ideias, Lista de Compras e dashboard personalizável — sem remover nada e sem perder dados.

**Architecture:** Mesma arquitetura v1 (Electron main dono do SQLite, IPC tipado `handlers.ts` → `ApiMethods`, renderer React + TanStack Query com invalidação global). Novas tabelas via migrações 003–007 (backup pré-migração automático). Novos serviços em `src/main/services/`, novas telas em `src/renderer/features/`.

**Tech Stack:** a da v1 + `react-grid-layout@2.3.0`.

**Spec:** `docs/superpowers/specs/2026-11-25-hub-v2-design.md` (§N = seção do spec). Spec v1 e plano v1 continuam valendo para o que não muda.

## Global Constraints

- Nada da v1 é removido; testes v1 continuam passando (só os `selectOption` viram helper `pick`).
- Migrações novas: `003_colors`, `004_day_blocks`, `005_ideas`, `006_shopping`, `007_dashboards` — cada uma com teste que cria dados antes e confere preservação.
- Raios: 5–6 px (cards 6, controles 5, selos 3). Sem gradientes, sem borda lateral colorida em cartões.
- Datas de bloco: `date` `YYYY-MM-DD`, horários `HH:mm` (00:00–24:00, passo 15 min na UI).
- Dinheiro: inteiro em centavos (`price_cents`); exibição `Intl.NumberFormat('pt-BR',{style:'currency',currency:'BRL'})`.
- Enums novos: ideia `status` `'new'|'analysis'|'developing'|'implemented'|'archived'` (Nova ideia/Em análise/Em desenvolvimento/Implementada/Arquivada); compra `status` `'pending'|'bought'`.
- Toda operação em massa em uma transação.
- UI pt-BR. `data-testid` existentes preservados.

## Review Focus

1. **Aba apontando para projeto/quadro excluído** → mostra "não encontrado" com botão fechar; nunca quebra a barra. Teste em Task 4.
2. **Blocos do Meu Dia nos limites**: fim ≤ início (VALIDATION), arrastar 23:30 com 1h para baixo (limita a 24:00 mantendo duração possível), sobreposição (permitida, lado a lado). Teste em Task 9.

4. **Reconstrução de `attachments` (005) num banco com anexos e índice de busca** → mesmos ids, mesmos caminhos, busca por nome de anexo continua funcionando. Teste em Task 11.
5. **Preços digitados como "12,50", "1.234,56", vazio, quantidade "1,5"** → centavos corretos e total certo. Teste em Task 14.

  - `activate(s, id)`, `moveTab(s, id, toIndex)` (fixa permanece em 0), `cycle(s, dir: 1 | -1)`, `activateIndex(s, n)`.
